MANHWA SLIME — المرحلة الثانية
================================

المحتويات:
- index.html: الموقع الرسمي.
- admin/index.html: تسجيل دخول الإدارة عبر Supabase Auth.
- admin/dashboard.html: لوحة عربية حقيقية للإصدارات والأخبار والإعدادات.
- functions/api/version.js: نقطة القراءة العامة /api/version.
- assets/supabase-config.js: رابط Supabase والمفتاح العام فقط.
- assets/images/logo.png: الصورة الأصلية لشعار السلايم.
- _headers: ترويسات أمان بسيطة.

الدخول إلى لوحة الإدارة:
-------------------------
افتح:
https://manhwa-slime.pages.dev/admin/

استخدم حساب Supabase الإداري. لا يوجد إنشاء حساب من صفحة الإدارة. حساب المالك المصرح به موجود في قاعدة البيانات الحالية، ويمكن للمالك إدارة الأدوار من نظام RBAC الموجود.

إعداد Cloudflare Pages:
-----------------------
أضف متغيري البيئة التاليين في Settings > Environment variables، للإنتاج والمعاينات:
- SUPABASE_URL = https://fqzdvcjekjgpdvomobre.supabase.co
- SUPABASE_ANON_KEY = المفتاح العام الموجود في assets/supabase-config.js

لا تضع SERVICE_ROLE_KEY أو أي مفتاح سري في ملفات الموقع.

استخدام اللوحة:
---------------
1. افتح /admin/ وسجّل الدخول.
2. من «إصدار جديد» اختر APK، واكتب versionName وversionCode والعنوان والتغييرات.
3. اضغط «حفظ كمسودة» للمعاينة أو «حفظ ونشر» للنشر مباشرة.
4. من «خبر جديد» أنشئ خبرًا كمسودة أو انشره.
5. من «إعدادات الموقع» عدّل البيانات العامة والإعلان.

التحقق من APK:
--------------
اللوحة تتحقق من الحجم (حتى 200MB) وتقرأ ترويسة ZIP الخاصة بملفات APK، ولا تعتمد على الامتداد وحده. التحقق العميق من شهادة APK وتوقيعه يمكن إضافته لاحقًا عبر خدمة خادم مخصصة إذا لزم.

الأمان:
-------
الجداول الجديدة تستخدم Row Level Security. القراءة العامة تقتصر على الإصدارات والأخبار المنشورة، والكتابة تتطلب صلاحية manage_releases أو manage_news أو manage_settings عبر Supabase. لا توجد مفاتيح خدمة سرية في المتصفح.

النشر من الهاتف:
-----------------
ارفع محتويات الحزمة بحيث يظهر index.html في الجذر، مع مجلدات admin وassets وfunctions. بعد النشر أضف متغيرات البيئة المذكورة أعلاه ثم أعد النشر إذا طلب Cloudflare ذلك.

حل ملفات APK الكبيرة:
----------------------
إذا ظهر خطأ The object exceeded the maximum allowed size، لا ترفع الملف إلى Supabase Storage. ارفع APK كملف من مرفقات GitHub Release ثم انسخ رابط Download الخاص بالملف، وبعدها ضع الرابط في حقل «رابط APK خارجي مباشر» في لوحة الإدارة. يجب أن يبدأ الرابط بـ https:// ويكون رابط تنزيل مباشرًا للملف.
