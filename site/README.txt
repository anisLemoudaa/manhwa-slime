MANHWA SLIME — نسخة جاهزة للنشر
================================

محتويات هذه الحزمة:
- index.html: الصفحة الرئيسية.
- assets/images/logo.png: الصورة الأصلية المرفقة لشعار السلايم الأزرق؛ لا يعتمد على مسار /_blob الداخلي.
- _headers: ترويسات أمان بسيطة لـ Cloudflare Pages.

حالة تنزيل التطبيق:
--------------------
لم يتم إرفاق ملف APK في المشروع الأصلي، لذلك زر التنزيل معطّل عمدًا ولا يوجد رابط وهمي.
عند توفر APK حقيقي، افتح index.html وابحث عن APK_CONFIG في آخر الملف، ثم عدّل:
- version: رقم الإصدار، مثل 1.0.0
- size: حجم الملف، مثل 45 MB
- releaseDate: تاريخ الإصدار
- downloadUrl: رابط HTTPS مباشر لملف APK الحقيقي
بعد ذلك ارفع index.html مجددًا.

النشر من هاتف Android عبر Cloudflare Pages:
---------------------------------------------
1. سجّل الدخول إلى dash.cloudflare.com.
2. افتح Workers & Pages ثم Create application ثم Pages.
3. اختر Upload assets (Direct Upload).
4. سمِّ المشروع manhwa-slime إذا كان الاسم متاحًا.
5. ارفع محتويات هذا المجلد كما هي، أو ارفع ملف ZIP بعد فكّه من مدير الملفات.
6. لا تضع Build command، واجعل مجلد الإخراج هو المجلد الذي يحتوي index.html.
7. اضغط Deploy ثم افتح https://manhwa-slime.pages.dev.

ملاحظة مهمة:
------------
لا توجد لوحة /admin في هذه النسخة. إنشاء لوحة آمنة لرفع APK وإدارة الأخبار يحتاج مرحلة منفصلة، ومصادقة للمالك، وتخزينًا مثل Cloudflare R2 أو خدمة بيانات؛ لا ينبغي تنفيذها داخل صفحة ثابتة بلا حماية.

الدعم:
-------
نموذج الدعم في الصفحة توضيحي حاليًا ولا يرسل البيانات إلى خادم. يجب ربطه لاحقًا بخدمة خلفية أو بريد مخصص قبل استخدامه فعليًا.
