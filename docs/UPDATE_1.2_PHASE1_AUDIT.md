## 1. ملخص تنفيذي

المشروع مبني على **Mihon** (fork من Tachiyomi) مع طبقات مخصصة كبيرة لـ:
- دعم الروايات (Novel) عبر محرك JavaScript متوافق مع LNReader (`novelQuickjs`)
- نظام عملات (Coin Wallet) + Unity Ads
- نظام VIP واشتراكات
- نظام اجتماعي (متابعات، تعليقات، ملفات شخصية)
- روايات المجتمع (Community Novels)
- نظام ترتيب القراء (Rank / XP / مسابقات)
- إنجازات وألقاب
- مزامنة سحابية عبر Supabase

الواجهات الظاهرة في الصور التسع تتوافق بشكل كبير مع الهوية المطلوبة في الوثيقة 1.2 (رمادي فاتح + أزرق + لمسات حمراء).

## 2. بنية المشروع الرئيسية

| الموديول | الوظيفة |
|---------|--------|
| `app` | نقطة الدخول، الواجهات الرئيسية، الإعلانات، العملات |
| `data` | قاعدة البيانات المحلية (Room) + المستودعات |

| `core/*` | أدوات مشتركة |

**نقاط الدخول الرئيسية:**
- `MainActivity` (Compose + Voyager navigation)
- نظام التنقل السفلي المخصص (5 أقسام: الرئيسية، المكتبة، الروايات، المانهوا، حسابي)
